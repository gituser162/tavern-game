# Таверна «Втомлений Грифон»

Прототип фентезійного симулятора власника таверни на Godot 4 (GDScript).
Дизайн гри описано в [docs/DESIGN.md](docs/DESIGN.md).

## Як запустити
1. Відкрий Godot 4.3 або новіший (перевірено на 4.7).
2. Import → вибери файл `project.godot` з цієї папки.
3. Натисни F5 (Run Project).

## Структура
- `scenes/main.tscn`: головна сцена (інтерфейс будується з коду).
- `scripts/game_data.gd`: предмети, категорії, сховища складу, клієнти, завдання та всі числа балансу.
- `scripts/storage.gd`: склад з окремих сховищ за категоріями (місткість у `STORAGES`).
- `scripts/storage_view.gd`: показує сховища, їхню заповненість і предмети.
- `scripts/game_state.gd`: автозавантаження `GameState`, усі правила гри.
- `scripts/wallet.gd`: гаманець (золоті монети).
- `scripts/main.gd`: інтерфейс, який перемальовується при зміні стану.
- `scripts/client_portrait.gd`: тимчасовий силует відвідувача (замінити на спрайти).
- `assets/backgrounds/tavern.png`: тимчасовий фон таверни (заміни файл своїм малюнком з тією ж назвою).
- `assets/coins/gold.png`: іконка золотого.
- `assets/icons-1.png` … `icons-5.png`: іконки предметів (сітка 14 × 8, координати в `ITEMS[...]["icon"]`).
